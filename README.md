🚀 Smart City Delivery System
Smart City Delivery System — это современная событийно-ориентированная система управления доставкой еды в умном городе. Проект демонстрирует использование микросервисной архитектуры, обработку потоковых данных в реальном времени и современные подходы к разработке распределенных систем.

🎯 Бизнес-ценность
Скорость: Обработка до 1000 заказов в минуту

Надёжность: Доступность с автоматическим восстановлением

Масштабируемость: Горизонтальное масштабирование всех сервисов

Прозрачность: Полный мониторинг и трассировка каждого заказа

✨ Ключевые возможности
⚡ Создание и управление заказами с полным жизненным циклом

📍 Отслеживание в реальном времени через WebSocket

🤖 Умное распределение курьеров на основе загруженности

📊 Аналитика и прогнозирование времени доставки

🔄 Событийная интеграция между сервисами через Kafka

🛡 Защита от сбоев с Circuit Breaker и Retry
